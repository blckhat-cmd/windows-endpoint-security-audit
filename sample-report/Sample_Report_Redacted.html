No.FindingSeverityDescriptionRecommendation
EP-01BitLocker (disk encryption)HIGHThe Windows drive is not fully encrypted or protection is off. (Third-party disk encryption, if any, cannot be detected by this script.) [PoC-1]Turn on BitLocker for the Windows drive and save the recovery key safely.
EP-02Firewall inbound allow rulesHIGH1 inbound allow rule(s) are too open (allow everything, or open a risky port to any address on the Public profile). [PoC-2]Delete or narrow these rules. Allow only the needed ports and only from trusted IP addresses.
EP-03Remote access toolsHIGHRemote access tool(s) found: UltraVNC. [PoC-3]Remove the tool if it is not approved. If approved, use strong authentication, limit who can connect, and keep it updated.
EP-04Software with known security flawsHIGH1 installed program(s) are older than the version that fixes known security flaws (WinRAR, 7-Zip, PuTTY). [PoC-4]Update these programs to the latest version.
EP-05Outdated applications (needs internet)MEDIUM18 app(s) are outdated, including important ones (browsers, Java, Adobe, Office, archive tools, etc.). [PoC-5]Update the listed applications.
EP-06Password policyMEDIUMMinimum password length is 0 (should be 8 or more). Password complexity is off (and the minimum length is below 14). [PoC-6]Set minimum length 8+ (12+ is better), turn on complexity, and lock accounts after 5-10 wrong tries.
EP-07SMB settingsMEDIUMSMB signing is not required on the server side. SMB signing is not required on the client side. [PoC-7]Turn off SMB1. Require SMB signing after testing that it works with the client network.
EP-08LLMNR and NetBIOSMEDIUMLLMNR is not disabled. NetBIOS over TCP/IP is on for at least one network adapter. [PoC-8]Disable LLMNR by policy and turn off NetBIOS over TCP/IP (they help attackers steal password hashes on the local network).
EP-09End-of-life softwareMEDIUM1 installed program(s) no longer get security updates: Microsoft Office Home and Student 2021 - en-us. [PoC-9]Upgrade to a supported version, or remove the software.
EP-10Defender hardening (exclusions, cloud, PUA, ASR)LOWNetwork protection is not enforced. No Attack Surface Reduction rules are set. [PoC-10]In Windows Security (or Defender policy): remove wide exclusions, turn on cloud protection, PUA, network protection, tamper protection and ASR rules.
EP-11EDR agentLOWNo running EDR agent found (normal antivirus is not EDR). [PoC-11]Install and onboard an EDR agent if the client policy requires it.
EP-12Secure Boot and TPMLOWSecure Boot is off or not supported. [PoC-12]Turn on Secure Boot (UEFI) and TPM in the BIOS settings if the hardware supports them.
EP-13USB storageLOWUSB storage is allowed. [PoC-13]Block USB storage by policy if the client does not need it.
EP-14Local user accountsLOWEnabled account(s) where Windows does not require a password, so a blank password is allowed (a password was set earlier, so one may exist; this script cannot prove it is blank): User1. [PoC-14]Disable Guest and the built-in Administrator, disable unused accounts, and set a strong password on every account.
EP-15Screen lock (inactivity)LOWNo auto-lock (15 minutes or less) was found in policy or screen saver. (A lock set only in Power settings is not read by this script.) [PoC-15]Set an inactivity lock of 15 minutes or less by policy.
EP-16Scheduled tasks (non-Microsoft)LOWScheduled task(s) point to a file in a Temp/Public folder that no longer exists: SystemOptimizerTemp. [PoC-16]Delete the leftover tasks.
EP-17Services (unsafe paths)LOWUnquoted service path(s) (not exploitable by normal users now): McAfee WebAdvisor. [PoC-17]Put service paths in quotes. Check services that run from user or temp folders.
EP-18Event log size and audit policyLOWSecurity log is only 20 MB (100 MB or more is recommended). [PoC-18]Increase the Security log size and audit logon success and failure.
EP-19PowerShell and command-line loggingLOWPowerShell script block logging is off. Command-line logging for new processes is off. [PoC-19]Turn on script block logging and command-line logging by policy. They help investigate attacks.
EP-20Browser extensions (Chrome and Edge)LOWExtension(s) can read all websites and also use powerful permissions (cookies, proxy, native apps): McAfee® WebAdvisor (fheoggkfdfchfphceeifdbepaooicaho); FoxyProxy (flcnoalcefgkhkinjkffipfdhglnpnem). [PoC-20]Remove extensions that are not approved. Allow only needed extensions.
EP-21Saved Wi-Fi networksLOWSaved open (no password) Wi-Fi network(s): HomeNet-5G, Neighbor-WiFi-2G. The PC may join them automatically. [PoC-21]Remove open Wi-Fi profiles. Use only protected networks.
EP-22SmartScreen and ransomware protectionLOWControlled Folder Access (ransomware protection) is off. [PoC-22]Turn on SmartScreen and Controlled Folder Access in Windows Security.
EP-23Memory protections (HVCI and DEP)LOWMemory integrity (HVCI) is not running. [PoC-23]Turn on Memory integrity in Windows Security > Device security > Core isolation. Keep DEP on.
EP-24Remote AssistanceLOWWindows Remote Assistance is allowed (invitation only). This is the Windows default. [PoC-24]Turn it off if it is not used.
EP-25Files that may hold passwords (names only)LOW1 file(s) in Downloads, Desktop or Documents have names that suggest stored passwords. (File contents were NOT read.) [PoC-25]Keep passwords in a password manager, not in plain files. Delete these files after moving the passwords.
